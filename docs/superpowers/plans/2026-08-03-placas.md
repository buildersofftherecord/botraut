# Generador de placas BOTR — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un bot de Slack que, a partir del nombre de un invitado, genera la placa de anuncio 1080×1080 de *Builders Off The Record* con la marca aplicada.

**Architecture:** Una app Next.js en Vercel. Chat SDK traduce entre Slack y tres handlers; el AI SDK (vía AI Gateway) redacta el copy; `sharp` procesa la foto; `@vercel/og` (Satori) renderiza el PNG en memoria. El estado entre turnos vive en Redis; las imágenes en Vercel Blob. No hay agente ni proceso persistente: cada turno es una función que se prende, trabaja y muere.

**Tech Stack:** Next.js 16 · TypeScript · `chat` (Chat SDK) + `@chat-adapter/slack` + `@chat-adapter/state-redis` · `ai` v6 (AI Gateway) · `@vercel/og` · `sharp` · `zod` · `@vercel/blob` · Vitest

**Spec:** `docs/superpowers/specs/2026-08-03-placas-design.md`

## Global Constraints

- **Ubicación:** proyecto nuevo en `BOTR/placas/`. **No** se mezcla con `BOTR/landing/`.
- **Idioma del código:** nombres de archivos, funciones, variables y tests en castellano, siguiendo la convención de `landing/` (`invitados`, `tipos`, `acciones`, `estados`).
- **Comentarios:** explican *por qué*, no *qué*. Densidad baja. Convención de `landing/`.
- **Un solo lienzo en el v1:** 1:1, 1080×1080. `Placa.tsx` recibe el lienzo como prop desde el día uno.
- **Colores exactos**, copiados de `landing/app/globals.css`, sin re-derivar: `--negro #000000` · `--carbon #0a0a0a` · `--gris #141414` · `--rojo #ff2b2b` · `--rojo-hondo #c81a1a` · `--linea rgba(255,255,255,0.1)`
- **HUD exacto**, copiado de `landing/app/globals.css`: esquina 26px, borde 1px `rgba(255,255,255,0.8)`; label 11px, `letter-spacing: 0.16em`, uppercase.
- **Fuentes versionadas en este repo** (a diferencia de `landing/`, que las gitignorea): Satori las necesita en runtime. Archivo e IBM Plex Mono son SIL OFL — va el `OFL.txt` al lado de cada una.
- **Satori no soporta `filter: grayscale()`.** Toda transformación de imagen pasa por `sharp` **antes** del template.
- **Tests:** Vitest, archivos `.test.ts` colocados al lado del módulo que prueban.
- **Commits:** frecuentes, uno por task como mínimo. Conventional commits.

```ts
// marca/fuentes/index.ts
import { readFile } from "node:fs/promises";
import { join, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const aca = dirname(fileURLToPath(import.meta.url));

export type Fuente = {
  name: string;
  data: Buffer;
  weight: 400 | 900;
  style: "normal";
};

/**
 * Satori necesita los bytes de la fuente, no un nombre de familia: no tiene
 * acceso a las fuentes del sistema ni a next/font. Por eso los .ttf se
 * versionan en este repo aunque `landing/` los gitignoree.
 */
export async function cargarFuentes(): Promise<Fuente[]> {
  const [archivo, mono] = await Promise.all([
    readFile(join(aca, "Archivo-900-125.ttf")),
    readFile(join(aca, "IBMPlexMono-Regular.ttf")),
  ]);

  return [
    { name: "Archivo", data: archivo, weight: 900, style: "normal" },
    { name: "IBMPlexMono", data: mono, weight: 400, style: "normal" },
  ];
}
```

```ts
// lib/tipos.ts
import { z } from "zod";

/**
 * Los límites de caracteres no son validación defensiva: son las medidas del
 * template. `nombre` sale de que "GUILLERMO RAUCH" ocupa dos líneas al cuerpo
 * de `LIENZOS["1:1"].nombreTamano`. El modelo recibe estos límites en el
 * prompt y se ajusta solo.
 */
export const InvitadoSchema = z.object({
  nombre: z.string().min(1).max(24),
  rol: z.string().min(1).max(70),
  /** El template dice INVITADA / INVITADO / INVITADX. Es un campo del diseño. */
  genero: z.enum(["f", "m", "x"]),
  fuentes: z.array(z.string().url()).min(1),
});

/**
 * El mínimo de 800px sale de que la foto se renderiza a ~1080 de alto: por
 * debajo de eso se pixela de forma visible.
 */
export const FotoSchema = z.object({
  url: z.string().url(),
  /** La página de donde salió, no el archivo. Es el rastro para derechos. */
  fuente: z.string().url(),
  ancho: z.number().int().min(800),
  alto: z.number().int().min(800),
});

export const PlacaSchema = z.object({
  invitado: InvitadoSchema,
  fotoElegida: FotoSchema,
  fecha: z.string().min(1),
  hora: z.string().min(1),
  enVivo: z.boolean(),
});

export type Invitado = z.infer<typeof InvitadoSchema>;
export type Foto = z.infer<typeof FotoSchema>;
export type DatosPlaca = z.infer<typeof PlacaSchema>;

/** El template dice INVITADA, INVITADO o INVITADX según el género. */
export function etiquetaInvitado(genero: Invitado["genero"]): string {
  return { f: "INVITADA", m: "INVITADO", x: "INVITADX" }[genero];
}
```

```ts
// test/pixel.ts
import sharp from "sharp";

/** Devuelve el RGB de un píxel del PNG. */
export async function pixelEn(
  png: Buffer,
  x: number,
  y: number,
): Promise<[number, number, number]> {
  const { data } = await sharp(png)
    .extract({ left: x, top: y, width: 1, height: 1 })
    .raw()
    .toBuffer({ resolveWithObject: true });
  return [data[0], data[1], data[2]];
}

export async function medidas(png: Buffer): Promise<{ ancho: number; alto: number }> {
  const m = await sharp(png).metadata();
  return { ancho: m.width!, alto: m.height! };
}
```

```tsx
// marca/Hud.tsx
import { HUD, COLOR, FUENTE } from "./tokens";
import type { Lienzo } from "./lienzos";

/**
 * Los cuatro corchetes de `.hud-corner` en globals.css: cada uno son dos
 * bordes de un div, no un carácter ni un SVG.
 */
export function Esquinas({ lienzo }: { lienzo: Lienzo }) {
  const m = lienzo.margen;
  const s = HUD.esquinaLado;
  const b = `${HUD.esquinaBorde}px solid ${HUD.esquinaColor}`;

  const posiciones = [
    { top: m, left: m, borderTop: b, borderLeft: b },
    { top: m, right: m, borderTop: b, borderRight: b },
    { bottom: m, left: m, borderBottom: b, borderLeft: b },
    { bottom: m, right: m, borderBottom: b, borderRight: b },
  ];

  return (
    <>
      {posiciones.map((p, i) => (
        <div key={i} style={{ position: "absolute", width: s, height: s, display: "flex", ...p }} />
      ))}
    </>
  );
}

/** El estilo de `.hud-label`: 11px, tracking 0.16em, mayúsculas. */
export function Etiqueta({
  children,
  color = COLOR.blanco,
}: {
  children: string;
  color?: string;
}) {
  return (
    <div
      style={{
        display: "flex",
        fontFamily: FUENTE.mono,
        fontSize: HUD.labelTamano,
        letterSpacing: HUD.labelTracking,
        textTransform: "uppercase",
        color,
      }}
    >
      {children}
    </div>
  );
}

export function PuntoRec({ tamano = 9 }: { tamano?: number }) {
  return (
    <div
      style={{
        display: "flex",
        width: tamano,
        height: tamano,
        borderRadius: tamano,
        background: COLOR.rojo,
      }}
    />
  );
}
```

```ts
// marca/texturas/generar-binario.ts
import sharp from "sharp";

/** PRNG determinista: `Math.random()` haría irreproducible la textura. */
function rng(semilla: number): () => number {
  let s = semilla >>> 0;
  return () => {
    s = (s * 1664525 + 1013904223) >>> 0;
    return s / 0x100000000;
  };
}

/**
 * Columnas de ceros y unos, muy por debajo del contraste del texto: es
 * atmósfera, no información. El tope de #262626 sale de `--gris #141414`
 * más un poco de aire.
 */
export async function generarBinario(
  ancho: number,
  alto: number,
  semilla: number,
): Promise<Buffer> {
  const azar = rng(semilla);
  const pasoX = 26;
  const pasoY = 22;
  const filas: string[] = [];

  for (let x = 0; x < ancho; x += pasoX) {
    for (let y = 0; y < alto; y += pasoY) {
      const digito = azar() > 0.5 ? "1" : "0";
      const luz = Math.floor(12 + azar() * 26);
      const hex = luz.toString(16).padStart(2, "0");
      filas.push(
        `<text x="${x}" y="${y}" font-family="monospace" font-size="15" fill="#${hex}${hex}${hex}">${digito}</text>`,
      );
    }
  }

  const svg = `<svg xmlns="http://www.w3.org/2000/svg" width="${ancho}" height="${alto}">
    <rect width="100%" height="100%" fill="#000000"/>${filas.join("")}</svg>`;

  return sharp(Buffer.from(svg)).png().toBuffer();
}
```

```ts
// lib/foto.ts
import sharp from "sharp";
import type { Foto } from "./tipos";

/** Debajo de esto no hay silueta de medio cuerpo para llevar al borde inferior. */
const PROPORCION_MAXIMA = 1.1;
const LADO_MINIMO = 800;

export type ResultadoValidacion =
  | { ok: true; foto: Pick<Foto, "ancho" | "alto"> }
  | { ok: false; motivo: string };

/**
 * De los cuatro requisitos de la spec §8, esto verifica uno y aproxima otro:
 * las medidas, y la proporción como proxy de "medio cuerpo". Que el fondo se
 * recorte limpio y que la persona esté bien expuesta no los puede juzgar ningún
 * filtro — los juzga el humano al elegir qué subir.
 *
 * Por eso `motivo` está escrito para leerse en Slack: es lo único que el
 * sistema puede decir sobre por qué una foto no sirve.
 */
export async function validarFoto(bytes: Buffer): Promise<ResultadoValidacion> {
  let ancho: number | undefined;
  let alto: number | undefined;

  try {
    ({ width: ancho, height: alto } = await sharp(bytes).metadata());
  } catch {
    return { ok: false, motivo: "No pude leer esa imagen. ¿Es un JPG o PNG?" };
  }

  if (!ancho || !alto) {
    return { ok: false, motivo: "No pude leer esa imagen. ¿Es un JPG o PNG?" };
  }

  if (ancho < LADO_MINIMO || alto < LADO_MINIMO) {
    return {
      ok: false,
      motivo:
        `Esa foto es de ${ancho}×${alto} y va a salir pixelada en la placa. ` +
        `Necesito al menos ${LADO_MINIMO}px de lado, idealmente 1200 o más.`,
    };
  }

  if (ancho / alto > PROPORCION_MAXIMA) {
    return {
      ok: false,
      motivo:
        `Esa foto es apaisada (${ancho}×${alto}) y la placa necesita una silueta ` +
        `vertical que llegue hasta el borde de abajo. Mandame una de medio cuerpo ` +
        `o cuerpo entero, más alta que ancha.`,
    };
  }

  return { ok: true, foto: { ancho, alto } };
}

/** El texto que el bot postea cuando pide la foto por primera vez. */
export const PEDIDO_DE_FOTO =
  "Mandame una foto: medio cuerpo o cuerpo entero, fondo limpio, " +
  "800px de lado o más. Cuanto más despejado el fondo, mejor sale el recorte.";
```

```ts
// lib/procesar.ts
import sharp from "sharp";

/** 15 MB: una foto de prensa razonable nunca los pasa. */
const MAXIMO_BYTES = 15_000_000;

export async function descargar(url: string): Promise<Buffer> {
  const r = await fetch(url);
  if (!r.ok) throw new Error(`descarga: HTTP ${r.status} en ${url}`);

  const largo = Number(r.headers.get("content-length") ?? 0);
  if (largo > MAXIMO_BYTES) throw new Error(`descarga: ${largo} bytes es demasiado`);

  return Buffer.from(await r.arrayBuffer());
}

/**
 * Satori no soporta `filter: grayscale()`, así que el B/N se hace acá.
 * `.grayscale()` solo no alcanza: colapsa a un canal y perdemos el alpha del
 * recorte, por eso el `.toColourspace("srgb")` después.
 */
export async function aBlancoYNegro(png: Buffer): Promise<Buffer> {
  return sharp(png).grayscale().toColourspace("srgb").png().toBuffer();
}

export async function ajustarAlto(png: Buffer, alto: number): Promise<Buffer> {
  return sharp(png).resize({ height: alto, fit: "inside" }).png().toBuffer();
}
```

```ts
// lib/almacenar.ts
import { put } from "@vercel/blob";

export type Etapa = "original" | "recortada" | "placa";

/**
 * La clave agrupa por invitado para poder ver de un vistazo qué se generó
 * para quién. `addRandomSuffix` evita pisar la versión anterior si rehacés
 * una placa.
 */
export function clavePara(nombre: string, etapa: Etapa): string {
  const slug = nombre
    .normalize("NFD")
    .replace(/[̀-ͯ]/g, "")
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-|-$/g, "");
  return `${slug}/${etapa}.png`;
}

export async function guardar(
  clave: string,
  datos: Buffer,
  tipo: string,
): Promise<string> {
  const { url } = await put(clave, datos, {
    access: "public",
    contentType: tipo,
    addRandomSuffix: true,
  });
  return url;
}
```

```ts
// lib/generar.ts
import { descargar, aBlancoYNegro, ajustarAlto } from "./procesar";
import { recortar } from "./recorte";
import { renderizar } from "../marca/Placa";
import { guardar, clavePara } from "./almacenar";
import { LIENZOS } from "../marca/lienzos";
import type { DatosPlaca } from "./tipos";

/**
 * El orden importa: recortar primero, porque el modelo de segmentación usa el
 * color para separar figura de fondo y sobre una imagen ya en gris pierde
 * señal. El resize va último para no gastar cómputo en píxeles que se tiran.
 *
 * Se guardan las tres etapas, no solo la placa: las URLs de internet se
 * pudren, y el recorte es el paso caro — si mañana rehacés la placa con otra
 * fecha, no querés volver a pagarlo.
 */
export async function generarPlaca(
  datos: DatosPlaca,
): Promise<{ png: Buffer; url: string }> {
  const nombre = datos.invitado.nombre;

  const original = await descargar(datos.fotoElegida.url);
  await guardar(clavePara(nombre, "original"), original, "image/jpeg");

  const recortada = await recortar(original);
  await guardar(clavePara(nombre, "recortada"), recortada, "image/png");

  const gris = await aBlancoYNegro(recortada);
  const foto = await ajustarAlto(gris, Math.round(LIENZOS["1:1"].alto * 0.94));

  const png = await renderizar(datos, "1:1", foto);
  const url = await guardar(clavePara(nombre, "placa"), png, "image/png");

  return { png, url };
}
```

```ts
import { z } from "zod";
```

```tsx
// bot.ts
import { Chat, Card, CardText, Image, Actions, Button } from "chat";
import { createSlackAdapter } from "@chat-adapter/slack";
import { createRedisState } from "@chat-adapter/state-redis";
import { buscarInvitado } from "./lib/buscar";
import { buscarFotos } from "./lib/fotos";
import type { EstadoThread } from "./lib/estado";

export const bot = new Chat({
  userName: "placas",
  adapters: { slack: createSlackAdapter() },
  state: createRedisState(),
  dedupeTtlMs: 600_000,
});

bot.onNewMessage(/^\s*(.+?)\s*$/, async (thread, message) => {
  const nombre = message.text.trim();

  // Slack exige ack en 3 segundos y la búsqueda tarda ~20. Este post es el
  // ack; el trabajo largo va después.
  await thread.post(`Buscando a ${nombre}...`);

  let invitado, candidatas;
  try {
    [invitado, candidatas] = await Promise.all([
      buscarInvitado(nombre),
      buscarFotos(nombre),
    ]);
  } catch (e) {
    await thread.post(
      `No pude armar la placa de *${nombre}*: ${(e as Error).message}\n` +
        `Probá con el nombre completo, o subí una foto al thread para cargarla a mano.`,
    );
    return;
  }

  if (candidatas.length === 0) {
    await thread.post(
      `Encontré a *${invitado.nombre}* (${invitado.rol}) pero ninguna foto sirve.\n` +
        `Subí una al thread: medio cuerpo, fondo limpio, 800px o más.`,
    );
    await thread.setState({ invitado, candidatas: [] } satisfies Partial<EstadoThread>);
    return;
  }

  await thread.setState({ invitado, candidatas } satisfies EstadoThread);

  await thread.post(
    <Card title={invitado.nombre}>
      <CardText>{invitado.rol}</CardText>
      {candidatas.map((f, i) => (
        <Image key={i} src={f.url} alt={`Candidata ${i + 1}`} />
      ))}
      <Actions>
        {candidatas.map((_, i) => (
          <Button key={i} id={`foto-${i}`}>{`Foto ${i + 1}`}</Button>
        ))}
        <Button id="editar">Editar copy</Button>
        <Button id="subir-foto" style="danger">Ninguna sirve</Button>
      </Actions>
    </Card>,
  );
});
```

## Notas para quien ejecute

**El camino crítico son las tasks 1-11.** Si el template no queda bien, nada de lo demás importa. Las tasks 12-14 son spikes y se pueden hacer en paralelo.

**El loop de diseño es `npm run placa`.** Renderiza en 2 segundos sin Slack, sin LLM y sin deploy. Toda la iteración visual de las tasks 7-11 pasa por ahí.

**Los valores de `marca/tokens.ts` no se ajustan a ojo.** Vienen de `landing/app/globals.css` y tienen un test que los fija. Si algo no cierra visualmente, lo que se mueve son las medidas de `marca/lienzos.ts` o los márgenes del template — nunca los colores ni el tracking del HUD.

**Los tests de píxel pueden pedir ajuste de coordenadas** después de mover el layout. Ajustar la coordenada del test a lo que muestra el PNG; no aflojar la aserción a `toBeGreaterThan(0)`.
